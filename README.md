# Outpost — Chess Training Coach

A free chess training site that runs entirely in the browser — no sign-up, works offline.

- **Lessons** — 13 interactive lessons, from how the pieces move to forks, pins and mating patterns
- **Puzzles** — 25 tactics puzzles with hints and an adaptive puzzle rating
- **Play** — pass & play with a friend on one device (with clocks), or play against the computer coach
- **Mini-games** — Secret Queen, Pawn Wars, Coordinate Rush and Knight Sprint

Progress is saved in your browser. Plain HTML, CSS and JavaScript — no build step: open `index.html` to run it locally.
